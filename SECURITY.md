# Security Policy

## Reporting a vulnerability

Do not open a public GitHub issue for a security vulnerability.

Send the report to **security@peersyst.com**, or use [GitHub private vulnerability reporting](https://github.com/xrplevm/node/security/advisories/new).

Include:

- the affected version or commit
- the steps to reproduce, or a proof of concept
- the impact you expect

We confirm receipt and keep you informed until the issue is fixed.

## Supported versions

Only the latest tagged release of `exrpd` receives security fixes. This is normally the version that runs on mainnet and testnet. See [releases](https://github.com/xrplevm/node/releases).
